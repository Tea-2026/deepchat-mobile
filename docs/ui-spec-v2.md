# UI 改版规格 v2（2026-11-20）

> 目标：把应用从"工具感"改成每天愿意用的对话应用。参考 DeepSeek App 的信息结构，但配色与动效按本规格。

## 1. 视觉基调

| 项 | 值 |
| --- | --- |
| 强调色 | 蓝，`#4D6BFE`（亮色）/ `#7C93FF`（暗色） |
| 警告色 | 红，`#E5484D` |
| 背景 | 亮 `#FFFFFF`，暗 `#000000`（纯黑，省电且现代） |
| 卡片/表层 | 亮 `#F5F6F8`，暗 `#141414` |
| 分隔线 | 亮 `#E6E8EC`，暗 `#262626` |
| 正文 | 亮 `#111111`，暗 `#EDEDED` |
| 次要文字 | 亮 `#6B7280`，暗 `#9CA3AF` |
| 圆角 | 输入区 24dp，卡片 20dp，按钮 999dp（胶囊） |
| 间距 | 4 的倍数，页面边距 16dp |

字体沿用系统字体；标题 22sp SemiBold，正文 16sp，辅助 13sp。数字（token/时间）用等宽数字特性。

动效沿用现有 `Motion` token，新增：抽屉滑出 260ms、底部面板进出 280/220ms、消息入场淡入+4dp 上移。

## 2. 导航结构

- **首页就是对话界面**，不再有"会话列表首屏"。
- 左上角汉堡按钮打开左侧抽屉：搜索框、新建对话、会话列表（文件夹/标签过滤保留）、底部设置入口。
- **草稿式新对话**：进入应用时是一个未落库的草稿对话；发送第一条消息时才 `conversations.create()` 并落库。未发送前切走再回来，草稿内容保留在内存中。
- 从抽屉选择一个历史会话，替换当前内容。

## 3. 聊天界面

- 顶栏：抽屉按钮、标题（自动标题后更新）、副标题「模型名 · 思考等级」、右侧溢出菜单（上下文调试 / 上下文注入 / 导出）。
- **助手消息**：无气泡，整段铺在背景上。首行是 `[品牌头像] 模型名  时间`，下面若有推理则显示折叠行「思考 3 秒 ›」，再下面是正文。
- **用户消息**：右对齐，胶囊气泡，强调色底、白字；上方一行 `时间 You [用户头像]`。
- 思考折叠行点击展开推理文本（斜体、次要色）。
- token/费用行保留，小字，右对齐，跟在助手消息下方。
- **消息操作**：长按改为**底部操作面板**（bottom sheet），避免当前操作条溢出裁切的问题。
- 空状态：草稿对话里保留引导与三条示例。

## 4. 输入区（参考 P1）

结构自上而下：

1. 待发送附件 chip 行（有附件时出现）
2. 多行输入框（1–6 行自适应），placeholder「发消息…」
3. 控制栏：
   - 左：`＋` 附件按钮
   - 模型 chip：品牌头像 + 模型名 + ▾，点击弹出模型选择
   - 思考等级 chip：图标 + 当前档位（关/低/中/高）
   - 联网 toggle：地球图标，开启时强调色填充
   - 右侧：高级参数图标、系统提示词图标、发送/停止按钮

发送键：空闲为向上箭头，生成中 morph 为停止方块，联网搜索中为转圈。

## 5. 半屏面板（点 ＋）

- 与输入法互斥：打开面板时收起键盘；点输入框时收起面板。
- 内容：
  - 最近照片网格（3 列，圆角 12dp）——需要相册权限，未授权时显示授权引导
  - 三个大按钮：拍照 / 相册 / 文件
  - 底部一行：高级参数、系统提示词（也可从这里进）
- 高级参数面板：温度、top-p、最大 token、停止序列；改动写入当前会话的 `overrides`，并显示"仅本会话"提示。
- 系统提示词面板：多行编辑当前会话的 systemPrompt，保存到 `overrides.systemPrompt`。

## 6. 设置（参考 P4）

一级页分组列表，每行：左图标 + 标题，右侧当前值 + `›`。

- **模型**：模型服务（n 个）、预设（n 个）
- **工具**：联网搜索（当前源）、生成（并发数）
- **数据**：导出 / 导入、存储占用
- **通用**：外观（跟随系统/浅色/深色）、字体大小、语言
- **关于**：版本、开源许可

二级页沿用同样的列表风格；危险操作用警告红。

## 7. 滑块

- 拖动时**本地 state 跟手**，松手后再写回存储；数值实时显示。
- 不使用"松手才跳"的实现；数值变化用 `animateFloatAsState` 过渡。

## 8. 头像

- 用户：圆底 + 人形图标（默认），可后续换。
- 模型：按 provider 协议选品牌 logo，资源已就位：
  - `R.drawable.ic_brand_deepseek`
  - `R.drawable.ic_brand_openai`
  - `R.drawable.ic_brand_anthropic`
  - `R.drawable.ic_brand_gemini`
- 未知 provider 用模型名首字母 + 强调色圆底。
- 品牌 logo 用白色 tint 放在深色圆底上（亮色模式用对比色圆底）。
